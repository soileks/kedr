# Мастерская «Кедр» — демо-сайт

Демонстрационный сайт мебельной мастерской для показа клиентам. Бренд, цены и отзывы вымышлены.

## Структура
- `docs/` — готовый сайт, его публикует GitHub Pages (`index.html`, `img/`).
- `kedr/index.html` — та же страница в формате для Claude Artifact (без `<html>`/`<head>`).
- `.claude/launch.json` — локальный предпросмотр: `python -m http.server 5173 --directory docs`.

## Как выложить на свой домен
1. **Репозиторий.** На github.com создать пустой публичный репозиторий `kedr` (без README) и отправить туда этот проект (`git push`).
2. **GitHub Pages.** В репозитории: Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, папка `/docs` → Save.
   Сайт откроется по адресу `https://<логин>.github.io/kedr/`.
3. **Домен.** Купить домен у регистратора (REG.RU, Timeweb, Beget и т. п.), например `ivanov-dev.ru`.
4. **DNS у регистратора.** Добавить запись:
   | Тип | Имя | Значение |
   |---|---|---|
   | CNAME | `kedr` | `<логин>.github.io.` |
5. **Привязка.** В `docs/` положить файл `CNAME` с одной строкой `kedr.ivanov-dev.ru`, закоммитить и отправить.
   В Settings → Pages в поле Custom domain должно появиться то же имя.
6. **HTTPS.** Когда DNS обновится (от 10 минут до суток), в Settings → Pages включить *Enforce HTTPS*.

Позже основной домен `ivanov-dev.ru` можно отдать под портфолио (репозиторий `<логин>.github.io` и записи A на IP GitHub Pages),
а каждое новое демо — на свой поддомен.
